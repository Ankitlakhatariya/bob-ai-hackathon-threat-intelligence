# Demo

This directory contains artifacts and links showcasing the demonstration of the project.

## Contents

- `demo-video-link.txt`: Link to the hosted demo video (YouTube, Loom, IBM Box, or Google Drive; 3–5 minutes).
- `live-demo-url.txt`: URL to the deployed application demo (or "NOT DEPLOYED" if running locally).
- `screenshots/`: Folder containing key screenshots of the running application (e.g. `01-landing-page.png`, `02-main-feature.png`).
